# Response Style

- Be concise by default. No restating the request, no filler summaries before or after code.
- Show only the changed code/diff, not the whole file, unless the whole file is requested.
- Do not re-explain the stack or conventions already defined in these rule files.
- Ask at most one clarifying question, and only if it's truly blocking. Otherwise pick the sensible default and note the assumption in one line.
